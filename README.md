# 📊 Social Media Big Data Analyzer


A Streamlit web application that analyzes Reddit trending topics using
Natural Language Processing (NLP), TF-IDF scoring, WordClouds, and
frequency analysis.


## 🚀 Features
- Live Reddit trending data (RSS feed)
- TF-IDF keyword importance
- Automatic topic category detection
- WordCloud visualization
- Repeated word frequency analysis
- Interactive search for TF-IDF score


## 🛠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- WordCloud
- Matplotlib


## ▶️ How to Run


```bash
pip install -r requirements.txt
streamlit run app.py
